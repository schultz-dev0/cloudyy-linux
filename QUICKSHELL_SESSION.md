## TL;DR — what's running right now

- **Waybar killed.** **swaync killed.** Both replaced by a single quickshell
  instance (`qs -d`) launched via `~/.config/hypr/source/shell-stack.conf`.
- Quickshell renders the **top bar** *and* the **notification system**
  (toasts + control-center panel) in one process.
- The shell is **theme-reactive**: matugen regenerates `Theme.qml` on every
  dark/light switch and quickshell hot-reloads it.
- The installer now has a **stack chooser** — users can pick `default`
  (waybar+swaync) or `quickshell`, with reserved slots for future swaps.

## QML architecture (the part you actually need to know)

### Two singletons, two responsibilities

| File | Role | Editable? |
|---|---|---|
| `Theme.qml` | Colors. Matugen-driven. Follows wallpaper + dark/light state. | **No.** It's overwritten on every theme switch. |
| `Style.qml` | Every size, radius, spacing, font size, ms duration, alpha. | **Yes — this is the file you tune.** |

Both QML entry points (`shell.qml`, `Notifications.qml`) `import "."` and
read `Style.<name>` / `Theme.<name>`. There are no raw integer literals in
business logic — every magic number lives in `Style.qml`, grouped by
component (top bar, pills, clock, workspaces, control center, quick actions,
DND row, toggle, notification cards, popups, history, sheen alphas, accents,
animations, battery polling).

### Hot reload

Quickshell auto-reloads on QML file change. Edit `Style.qml`, save, watch the
bar resize. No restart needed.

### Adding a new tunable

```qml
// Style.qml
readonly property int barShadowOffset: 4

// shell.qml
Rectangle { anchors.topMargin: Style.barShadowOffset }
```

### Adding a new component

1. Create `Foo.qml` in `~/.config/quickshell/`.
2. Register in `qmldir`: `Foo 1.0 Foo.qml`
3. Use as `Foo {}` from `shell.qml`.
4. Read sizes from `Style`, colors from `Theme`. If you need new tunables,
   add them to `Style.qml` first.

## IPC contract (replaces swaync-client)

The notification system exposes one IPC target with four functions:

| Command | Purpose |
|---|---|
| `qs ipc call notifs toggle` | toggle control center |
| `qs ipc call notifs dnd` | toggle Do Not Disturb |
| `qs ipc call notifs dismissLast` | dismiss top-most popup |
| `qs ipc call notifs clear` | wipe history + popups |

Hypr binds (already wired in `user_bindings.conf` and `source/bindings.conf`):

| Key | Action |
|---|---|
| `Mod+N` | toggle |
| `Mod+Shift+N` | dnd |
| `Mod+Ctrl+N` | dismissLast |

## Installer stack chooser

### How it's used

```bash
bash ~/cloudyy-linux/install/select-shell-stack.sh
```

Prompts the user to pick a profile, persists to
`~/.local/share/cloudyy/shell-stack`, and writes
`~/.config/hypr/source/shell-stack.conf` (the file Hyprland sources for
stack-managed `exec-once` lines). Live-reloads Hyprland if running.

### Profiles defined today

- **default** — Waybar + SwayNC (the original cloudyy-linux stack)
- **quickshell** — unified QML shell (current default)

### Component slots (extend freely)

Each profile defines per-slot impl + exec-once:
- `bar`
- `notifications`
- `launcher` *(both currently rofi)*
- `volume_osd` *(both currently swayosd)*
- `app_menu` *(reserved, empty)*
- `power_menu` *(both currently rofi)*

To add a new slot, append it to the `SLOTS=()` list in
`apply-shell-stack.sh` and add `SLOT_<profile>_<slot>` +
`EXEC_<profile>_<slot>` lines per profile in `shell-stack.conf`.

To add a new profile, push its key into `PROFILES`.

### How install.sh consumes it

New phase order:

```
preflight → shell_stack → dotfiles → packages → services → finalize
```

- `phase_shell_stack` runs `select-shell-stack.sh` (interactive)
- `phase_dotfiles` calls `apply-shell-stack.sh` after symlinks land
- `phase_packages` exports `CLOUDYY_SHELL_STACK` so `hyprland-install.sh`
  installs the profile's official+AUR packages alongside mandatory ones
  (new "Shell Stack" group in pacman_install / aur_install output)

## Hyprland integration details

### layerrule syntax (correct form)

```
layerrule {
    name            = quickshell_panel
    match:namespace = ^(quickshell)$
    blur            = on
    ignore_alpha    = 0.2
}
```

The compact `layerrule = blur, namespace` form is **not** what this repo uses.

### autostart

Stack-managed `exec-once` lines (waybar / swaync / `qs -d` / future bar
replacements) live ONLY in `~/.config/hypr/source/shell-stack.conf`. They
have been stripped from `source/autostart.conf` and
`user-configs/user_autostart.conf`. Don't put them back there.

### Quickshell layer surfaces

When running, you should see three with `hyprctl layers`:

```
namespace: quickshell  xywh: <full-width> 38   ← top bar
namespace: quickshell  xywh: 360 ...           ← popup overlay (when popups exist)
namespace: quickshell  xywh: 380 ...           ← control center (when open)
```

  would be `Quickshell.Services.UPower`

- ❌ Drop shadow is a 1px border fake; could move to `MultiEffect.shadowEnabled`
- ❌ Slide-in control center has no transition animation
- ❌ `~/cloudyy_scripts/swaync/` directory is unused but not deleted

These were left for the user to address themselves; do not silently fix
them in a future session unless asked.

# Send a normal + critical notification
notify-send "Test" "Body text"
