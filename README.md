As of 22nd Feb 2026 the install script is reliable and can be safely used. Although there may be a missing dependency, scripts and apps will install any missing dependency if needed

## Install instructions: 

# Requirements:
```bash
Sudo pacman -S git
```
```bash
git clone https://github.com/schultz-dev0/cloudyy-linux ~/CloudyyOS
```
```bash
./CloudyyOS/install.sh
```
* Follow the prompts and it will automatically deploy and symlink all the dotfiles*
